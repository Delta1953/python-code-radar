# Python Code de Radar
Proyecto de un Radar de Trading desarrollado en Python
## Objetivo
Detectar oportunidades de corto plazo en criptomonedas mediante el análisis de:
- Tendencia
- Impulso
- Liquidez
- Volatilidad
- Indicadores Técnicos
## Tecnologías
- Python
- Visual Studio Code
- Git/Github
- Github Copilot
